# (4.1) Cybersecurity Devices and Technologies

<u>Security Appliances:</u>
- **Routers** = interconnect various network segments together, also providing basic traffic filtering → help define which computers from a specific network segment can communicate with other network segments + filtering, encryption, etc
- **Firewalls** = looks deeper into network traffic and identifies malicious behavior that needs to be blocked → has sophisticated security policies applied + shows what happening on the network
- **Intrusion Prevention Systems (IPS)** = uses set traffic signatures that match and block malicious traffic and attacks.
- **Virtual Private Networks (VPN)** = let remote employees use a secure encrypted tunnel from their device and securely connect back to organization's network. 
- **Antimalware or Antivirus** = uses signatures or behavioral analysis of applications to identify and block malicious code from being executed + endpoint protection, scanning, and monitoring files for malicious behavior.

<u>Firewalls:</u>
- **Firewalls** = control and filter which communications are allowed in and which are allowed out of a device or network (single or whole network).
	- **Network Layer Firewall** = filters based on source and destination IP address + predefined rules
	- **Transport Layer Firewall** = filters based on source and destination data ports, as well as connection states
	- **Application Layer Firewall** = filters based on application, program, or service.
	- **Context Aware Layer Firewall** = filters based on user, device, role, application type and threat profile.
	- **Proxy Server** = filters web content like URLs, domain names, and media types.
	- **Reverse Proxy Server** = protect, hide, offload, and distribute access to web servers (placed in front of web servers)
	- **Network Address Translation (NAT) Firewall** = hides or masks the private addresses of network hosts + translate private IP addresses into a single public IP address
	- **Host-Based Firewall** = filters ports and system service calls on a single OS.

<u>Port Scanning:</u>
- In Networking, each application running on a device is assigned an identifier called a **Port Number**
	- used on both ends of transmission so the right data is passed to the correct application!
- **"Port Scanning"** is a process of probing a computer, server, or host for open ports
- **Nmap** is a very popular port scanning tool used by many cybersecurity professionals and hackers

<u>Real-Time Detection:</u>
- Detecting attacks in real-time requires actively scanning for attacks using firewall and **IDS/IPS** network devices + connections to global threat centers and malware detection client/servers.
- **Distributed Denial of Service (DDoS)** attacks are one of the biggest threats that require real-time detection and response.

<u>Protecting Against Malware:</u>
- One way of defending against **Zero-Day attacks** (hackers exploiting software flaws before creators have the chance to fix them!) and **Advanced Persistent Threats (APT)** is to use an enterprise-level advanced malware detection solution.
	- **Cisco Threat Grid**:
		- **Secure Operations Center Team** = gather more accurate, actionable data
		- **Incidence Response Team** = access to forensically sound info from which it can quickly analyze and understand suspicious behaviors.
		- **Threat Intelligence Team** = improve organization's security infra.
		- **Security Infrastructure Team** = consume and act on threat info faster, even in an automated way.

<u>Security Best Practices:</u>
- **Perform a Risk Assessment** = knowing/understanding value of what you are protecting will help justify security expenditures (funds/spending)
- **Create Security Policy** = create policy outlining organization's rules, job roles, and responsibilities + employee expectations.
- **Physical Security Measures** = restrict access to networking closets and server locations + fire suppression systems
- **Human Resource Security Measures** = background checks for all employees
- **Perform and test backups** = back up info regularly and test data recovery
- **Maintain Security Patches and Update**s = regularly update servers, client, and network device OS and programs.
- **Employ Access Control** = configure user roles and privilege levels as well as strong user authentication.
- **Regularly Test Incident Response** = employ IR team and test emergency response scenarios
- **Implement network monitoring, analytics, and management tool** = choose a security monitoring solution integrating with other technologies
- **Network Security Devices** = routers, firewalls, etc.
- **Endpoint Security Solution** = antimalware and antivirus software
- **Educate Users** = training for employees
- **Encrypt Data** = encrypt all organizational data including email.

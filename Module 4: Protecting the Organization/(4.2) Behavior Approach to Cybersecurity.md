# (4.2) Behavior Approach to Cybersecurity

<u>Behavior-Based Security:</u>
- **Behavior-Based Security** = threat detection that involves capturing and analyzing flow of communication between user on local network and local/remote destination.
	- **Honeypots** = behavior-based detection tool that lures attackers by appealing to their predicted pattern of malicious behavior → once attacker is inside the honeypot, network admins can capture/log/analyze behavior.
	- **Cisco Cyber Threat Defense Solution Architecture** = behavior-based detection and indicators to provide visibility, context, and control + know who/what/where/how attacking.

**Cisco's Snort** = perform real-time traffic and port analysis, and can also detect port scans, fingerprinting and buffer overflow attacks

**NetFlow** = tech used to gather information about data flowing through a network (who/what, and when/how) 
- important for behavior-based detection and analysis
- switches, routers, and firewalls equipped with NetFlow can report info about data entering, leaving, and travelling.

<u>What is Penetration Testing?</u>
- **Penetration Testing** = act of accessing a computer system, network, or organization for security vulnerabilities  → breaches systems, people, processes, code, etc to uncover vulnerabilities which could be exploited.

<u>Five Step Pen Test Process:</u>
1) **Planning** = gather as much info as possible about target system or network (potential vulnerabilities + active/passive reconnaissance + vuln research)
2) **Scanning** = carries out active reconnaissance to probe a target system/network and identify potential weaknesses 
	- includes: port scanning, vuln scanning, establish connection (enumeration) to target to identify user acc, system acc, and admin acc.
3) **Gaining Access** = attempt to gain access to target system and sniff network traffic
	- various methods such as: launching exploit payload, breaching, social engineering, web exploit, exploit software/hardware, beach access controls, cracking Wi-Fi, etc.
4) **Maintaining Access** = maintain access to target to find out what data and systems are vulnerable to exploitation → important they stay undetected, using: backdoors,, Trojan horses, rootkits, etc. 
5) **Analysis and Reporting** = provide feedback via a report that recommends updates to products, policies, and training to improve security.

<u>Impact Reduction:</u>
- **Communicate**
- **Be sincere and accountable**
- **Provide details**
- **Find cause**
- **Apply lessons learned**
- **Check, and check again**
- **Educate!**

<u>What is Risk Management?</u>
- **Risk Management** = process of continuously identifying and assessing risk in an effort to reduce the impact of threats and vulnerabilities.
	- **Frame Risk** = identify threats that increase risk
	- **Assess the Risk** = determine severity that each threat poses
	- **Respond to the Risk** = develop action plan to reduce overall organization risk exposure
	- **Monitor the Risk** = continuously review any risk reduced through elimination
